# فواتيري أوفلاين | Fawateery Offline

**نظام متكامل لإدارة المنتجات والمخزون والفواتير، يعمل بدون إنترنت.**

فواتيري أوفلاين هو تطبيق لإدارة المبيعات والمنتجات والمخزون وإصدار الفواتير، مصمم لمساعدة أصحاب المحلات والأنشطة التجارية على إدارة أعمالهم بسهولة من خلال أجهزة Windows وAndroid، دون الحاجة إلى اتصال دائم بالإنترنت.

---

## ✨ المميزات | Features

- إدارة المنتجات والأصناف.
- إدارة المخزون والكميات.
- إنشاء وإدارة فواتير المبيعات.
- طباعة الفواتير بمقاسات A4 و80mm.
- مشاركة الفواتير.
- إدارة بيانات المنشأة والعملاء.
- النسخ الاحتياطي واستعادة البيانات.
- العمل دون اتصال بالإنترنت (Offline).
- نظام تفعيل وترخيص للتطبيق.

## 💻 الأنظمة المدعومة | Supported Platforms

- Windows
- Android

## 🚀 التثبيت | Installation

### Android
1. ثبّت التطبيق باستخدام ملف APK.
2. وافق على التثبيت إذا طلب النظام ذلك.

### Windows
1. فك ضغط ملف التطبيق بالكامل.
2. شغّل `fawateery_offline.exe` من مجلد الإصدار.



## 🔒 الخصوصية والبيانات | Privacy & Data

تم تصميم التطبيق للعمل محليًا دون الحاجة إلى اتصال دائم بالإنترنت، وتُحفظ بيانات التطبيق محليًا على الجهاز.

احرص على إنشاء نسخ احتياطية منتظمة من بياناتك.
